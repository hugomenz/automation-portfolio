# Video Script — Machine Service Triage

Target length: 30–90 seconds. Start with the business input, not n8n.

| Time | Picture | Voice-over |
|---|---|---|
| 0–08 s | Service-E-Mail „Anlage steht“ zeigen. | Eine dringende Serviceanfrage ist oft noch kein bearbeitbarer Servicefall. |
| 08–19 s | Maschinenkarte und Eingangsdaten zeigen. | Der Workflow ordnet Maschine, Baureihe, Fehlercode und Auswirkung zu. |
| 19–32 s | Testfall „Sicherheitsrelevanter Hinweis“ starten. | Bei einer Schutztürmeldung nach Umbau muss das System aufhören, technisch zu raten. |
| 32–45 s | Rote Ausnahme und „keine Ferndiagnose“ zeigen. | Der Fall wird manuell eskaliert. Fehlende Evidenz bleibt sichtbar. |
| 45–58 s | Ticket-Payload und Audit öffnen. | Vorbereitet werden Priorität, zuständige Queue, Rückfragen und Quellen—nicht die Ursache. |
| 58–67 s | 0 Writes und Status einblenden. | Das Ziel: schneller beim Fachmenschen, ohne falsche Sicherheit. |

End card: `Synthetic Demo · Built and testable · 0 external writes · Nicht kundenvalidiert`.
